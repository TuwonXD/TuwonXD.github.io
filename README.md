# 💌 A Little Question... 🌸

A sweet, interactive web experience designed to ask someone out on the perfect date! 

Instead of just asking "wanna hang out?", this project takes the user through a fun, customizable questionnaire to plan the ideal date together—from food to activities, to the all-important matcha order. 🍵✨

## 🌟 Features

* **Interactive Questionnaire:** 5 customizable questions to build the perfect date itinerary.
* **Custom Inputs:** If the predefined options aren't enough, users can type in their own ideas! ✏️
* **The "Run-Away" Button:** A cheeky "No" button that playfully dodges clicks so they *have* to say yes. 🏃‍♂️💨
* **Downloadable Itinerary:** Once they say yes, a personalized "Date Plan" card is generated and can be downloaded as an image to save the memories. 📸
* **Secret Lock Screen:** A hidden screen accessible via a subtle lock icon, requiring a special date code (`060526`) to unlock a surprise question. 🔐
* **Cute Animations:** Custom cursor, floating lily petals, confetti pops, and smooth screen transitions. ✨

## 🛠️ Tech Stack

* **HTML5:** Structure and screens.
* **CSS3:** Glassmorphism card effects, CSS keyframe animations (floating, bouncing, shaking), custom properties, and responsive design.
* **Vanilla JavaScript:** State management (tracking user picks), DOM manipulation, and dynamic styling.
* **[html2canvas](https://html2canvas.hertzen.com/):** Used to capture the final date plan DOM element and convert it into a downloadable PNG.

## 🚀 How to Run

1. Clone or download this repository.
2. Ensure all three files are in the same folder:
   * `index.html`
   * `style.css`
   * `script.js`
3. Double-click `index.html` to open it in your favorite web browser. 
4. No build steps, servers, or dependencies required! (Though an active internet connection is needed to load the Google Fonts and the html2canvas CDN).

## 🤫 Psst... The Secret Code
If you find the tiny 🔒 icon on the welcome screen, enter the passcode **`060526`** to unlock a special surprise message!
